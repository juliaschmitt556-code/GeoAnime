Build a premium, production-ready GPS Location-Sharing Progressive Web App (PWA) called GeoAnime.

The app should be mobile-first, extremely polished, responsive, fast, and installable as a PWA. The visual identity should combine futuristic GPS technology with high-quality original anime artwork.

CORE PURPOSE

The app allows a user to:

1. Request permission to access their device GPS location.
2. Get their current latitude and longitude.
3. Continuously monitor their location using navigator.geolocation.watchPosition().
4. Convert coordinates into a complete readable address using reverse geocoding.
5. Display:
    * Street
    * House/building number when available
    * Avenue/Road
    * Neighborhood/Area
    * City
    * State/Province
    * Country
    * Postal code when available
    * Latitude
    * Longitude
    * GPS accuracy
    * Altitude when available
    * Speed when available
    * Heading/direction when available
    * Last updated time
6. Display the position on an interactive map.
7. Generate a unique shareable location URL.
8. Allow the user to share the location through the device’s native share sheet.
9. Support a live-location mode that updates as the user moves.
10. Allow the user to stop live location sharing at any time.

IMPORTANT GPS REQUIREMENTS

Use the browser Geolocation API.

For one-time location:

navigator.geolocation.getCurrentPosition()

For continuous tracking:

navigator.geolocation.watchPosition()

Use:

{
  enableHighAccuracy: true,
  timeout: 15000,
  maximumAge: 5000
}

Handle all permission states and GPS errors gracefully.

The app must clearly explain that location access requires explicit browser permission and HTTPS.

Never attempt to spoof, override, or silently change the device’s GPS location.

Create two modes.

1. SHARE CURRENT LOCATION

Capture the user’s current position and create a shareable location session.

Example:

The recipient should be able to open the link without needing an account.

Show:

* Shared address
* Coordinates
* Accuracy

2. LIVE LOCATION

Create a temporary live-sharing session.

Example:
